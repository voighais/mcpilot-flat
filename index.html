Frequently Asked Questions

What is the difference between Flat and Full?
Flat is the lightweight version without blur, animations or gradients. Only the essentials: console, files, editor, backups, multi-server. The Full version adds 8 themes, a custom background, CPU and RAM graphs, sounds, community themes and fine opacity control.
Which version should I choose?
If you have a modern PC with a dedicated GPU — go for Full. If you have a laptop older than 5 years, an i3 or Celeron, integrated graphics, or you just want nothing to eat your resources — go for Flat.
When is Flat coming out?
Flat is currently in closed testing. The public release will show up here and in the Telegram channel. Follow for updates.
Is it safe?
Yes. McPilot is open source under the MIT license. No network requests, no payments, no telemetry. You can open app.py and check every line. All the code lives on GitHub.
Where can I download the Full version?
The Full version lives on its own site. There you will find a feature overview, screenshots, a list of releases, and download links. Use the link below.
Does it work on Linux and macOS?
Yes. On Linux and macOS use .jar or .sh files, on Windows — .bat. McPilot detects the file type and runs the right command automatically.
Is it free?
Yes, completely free. MIT license — do whatever you want, fork, modify, redistribute. No built-in payments or ads.
